# 💰 Miniguia de Educação Financeira com NotebookLM

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um **desafio da DIO (Sem Parar Corpay - Banck-end do Zero a Patrica)**, com o objetivo de utilizar Inteligência Artificial como ferramenta de apoio aos estudos.

A proposta foi criar um miniguia de **Educação Financeira Pessoal** utilizando o **NotebookLM**, reunindo fontes confiáveis e criando prompts para facilitar o aprendizado.

Durante o projeto foram estudados conceitos básicos como:

* 💵 Organização financeira
* 📊 Orçamento pessoal
* 💳 Receitas e despesas
* 📈 Juros simples e compostos
* 🛡️ Reserva de emergência
* 💰 Liquidez, risco, inflação e rentabilidade

---

## 🧠 Uso do NotebookLM

O **NotebookLM** foi utilizado para organizar as fontes de estudo, gerar resumos, comparar conceitos e testar diferentes tipos de prompts.

Também foram registrados exemplos de prompts simples e versões melhoradas, mostrando como uma pergunta mais bem estruturada pode gerar respostas mais completas e úteis.

---

## 🎯 Objetivo do projeto

O principal objetivo foi aprender, na prática, como utilizar ferramentas de **Inteligência Artificial para estudar e organizar conhecimento**, ao mesmo tempo em que foram explorados conceitos importantes de educação financeira.

---
